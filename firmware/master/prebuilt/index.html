Firmware flashen

Firmware direkt aus dem Browser aufspielen — die Master-Steuerung über die USB-C-Buchse des ESP32-C3, die Daughter Card über einen USB-Seriell-Adapter (experimentell).

Dieser Browser kann kein Web Serial. Nutze Chrome oder Edge auf dem Desktop. Web Serial ist hier blockiert (funktioniert nur über HTTPS).

Ziel: ESP32-C3 · Image wird geladen…

Beim Flashen wird der Chip komplett gelöscht (auch die WLAN-Zugangsdaten). Kein BOOT-Taster nötig — der C3 geht über USB selbst in den Download-Modus.

Voraussetzungen

  • Chrome oder Edge auf dem Desktop (Web Serial API).
  • USB-C-Kabel mit Datenadern direkt an die Buchse des Moduls.
  • Das Modul muss nicht auf dem Trägerboard stecken.

Nach dem Flashen

  • Status-LED (GPIO6) blinkt schnell — noch kein WLAN.
  • Das Modul öffnet den Access-Point krone_anzeige. Dort im Captive-Portal die WLAN-Zugangsdaten eingeben.
  • LED-Dauerlicht = verbunden und alle Module erreichbar. Langsames Blinken = ein Modul offline oder im Fehler.
  • Spätere Updates laufen über die Web-UI des Moduls (Einstellungen › Firmware aktualisieren, signierter .kota-Container).
  • Serielle Konsole auf USB-C, 115200 Bd.

Ohne Browser

esptool.py --chip esp32c3 -p /dev/ttyACM0 \
  write_flash 0x0 krone-master-esp32c3.factory.bin
Experimentell Der UPDI-Flasher ist am Gerät noch nicht verifiziert. Klappt es nicht, bleibt pio run -e attiny1616 -t upload der sichere Weg. Rückmeldungen willkommen.

Ziel: ATtiny1616 · Image wird geladen…

Der Baustein wird komplett gelöscht (auch die im EEPROM abgelegte Busadresse — die wird beim nächsten Start neu vergeben). Vor dem Schreiben prüft der Flasher die Geräte-ID.

Verkabelung

USB-Seriell-Adapter (FTDI / CP2102 / CH340), auf 5 V gestellt, mit einem 4,7-kΩ-Widerstand zwischen TXD und RXD an die UPDI-Stiftleiste J6 (1×3):

  • An UPDI kein Kondensator (Schaltplan 4.4).
  • GND immer verbinden. 5V weglassen, wenn die Karte schon vom Netzteil / Bus versorgt wird (sonst Rückspeisung).
  • Beim Klick auf „Adapter verbinden" im Port-Dialog den USB-Seriell-Adapter wählen.

Ohne Browser

pio run -e attiny1616 -t upload -d firmware/module
